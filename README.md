# GOLDEN_KIDS SQL Project

## Overview
This project contains SQL scripts for creating and managing a **GOLDEN_KIDS database**.  
It includes table definitions and sample data population scripts, focusing on a **Student Table**.

## Project Structure
- **CREATE GOLDEN_KIDS DATABASE.sql**  
  Script to create the main database structure.

- **STUDENT TABLE.sql**  
  Script to define the schema for the `Student` table.

- **POPULATING STUDENT TABLE.sql**  
  Script to insert sample records into the `Student` table.
